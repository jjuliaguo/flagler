# Flagler Health: Code Review Mock Exercises

Three short, unfamiliar snippets to practice **explaining, tracing, debugging, and evaluating** code out loud.

| # | File | Context | Themes |
|---|------|---------|--------|
| 1 | `exercise_1_lab_summary.py` | Healthcare lab results | dicts, state, edge cases |
| 2 | `exercise_2_claim_submitter.py` | Insurance claim submission | retries, idempotency, duplicates, concurrency |
| 3 | `exercise_3_conflicts.ts` | Provider scheduling (TypeScript) | dates, sorting, algorithm correctness |

## How to practice
1. Open one exercise. Set a timer for about 15 minutes.
2. Out loud: explain inputs and outputs, then the execution flow.
3. Make up a small input and trace it by hand.
4. List bugs and edge cases, most severe first, with fixes.
5. Discuss complexity and what you'd change in production.
6. Only then open `ANSWER_KEY.md`, which has the interviewer questions, traces, and answers.
